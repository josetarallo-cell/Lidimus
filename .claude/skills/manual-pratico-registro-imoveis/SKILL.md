## Princípios Fundamentais do Registro de Imóveis

### Os Seis Princípios Nucleares

1. **Continuidade**: o transmitente deve ser o proprietário tabular atual. Romper a cadeia = desqualificação.

2. **Especialidade Objetiva**: imóvel deve ser descrito de forma identificável e compatível com a matrícula.

3. **Especialidade Subjetiva**: nome, estado civil e qualificação do transmitente no título devem corresponder à matrícula; divergências exigem certidões complementares.

4. **Publicidade**: o registro gera eficácia erga omnes; terceiros presumem-se cientes do fólio real.

5. **Prioridade/Prenotação**: *prior in tempore, potior in jure* — prevalece o título com número de protocolo anterior.

6. **Legalidade**: registrador verifica legalidade extrínseca; não revisa mérito de negócios ou decisões judiciais.

### Princípio Implícito: Tempus Regit Actum
Os requisitos aplicáveis são os da lei vigente ao tempo da prática do ato, não os da data do ingresso no RI.

## Core Frameworks

### Framework 1: Qualificação Registral
```
VERIFICA (extrínseco)             | NÃO VERIFICA (intrínseco)
────────────────────────────────  | ──────────────────────────────
• Forma do documento              | • Mérito de decisão judicial
• Continuidade da cadeia          | • Preço justo da CV
• Especialidade objetiva/subjetiva| • Validade interna do negócio
• Competência do tabelião         | • Conveniência do ato
• Impostos recolhidos             | • Constitucionalidade de leis
```

### Framework 2: Modo de Aquisição da Propriedade Imóvel
```
TÍTULO (contrato/sentença) + REGISTRO no Livro 2 = TRANSMISSÃO DE DOMÍNIO
                               ↑
                    sem registro: só crédito obrigacional
```

### Framework 3: Presunção de Fraude à Execução
```
COM penhora inscrita → presunção ABSOLUTA (sem provar má-fé)
COM averbação premonitória → presunção de fraude
SEM penhora inscrita → credor prova má-fé do adquirente (STJ REsp 956.943)
```

### Framework 4: Usucapião — Modo Originário
```
Usucapião ≠ transmissão
• Abre nova matrícula (não registra na anterior)
• Extingue todos os gravames (hipotecas, penhoras)
• Sem ITBI (salvo lei municipal específica)
• Dívidas tributárias anteriores não se transferem
```

### Framework 5: Fluxo de Consolidação da AF
```
Inadimplemento → Notificação pessoal (15 dias para purgar)
→ Não purgou → Requer consolidação ao RI
→ RI intima fiduciante (15 dias) → Sem resposta
→ ITBI recolhido → Consolidação registrada
→ Leilão 30 dias (1º: valor de mercado) → 15 dias (2º: valor da dívida)
→ Sem lance: quita a dívida / Com lance: saldo ao fiduciante
```
